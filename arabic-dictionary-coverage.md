# Arabic dictionary expansion

## Added in this update

- Arabic names for all 15 missions.
- Arabic subtitles for the first four mission entries; remaining detailed descriptions are not yet fully localized.
- Arabic headings for all lesson cards across the 15 missions.
- Arabic names for all 15 mission activities.
- Arabic labels for all planet names (Mercury through Neptune and the Sun) and common planet-stat fields.
- Arabic translations for common lesson, quiz, navigation, and activity controls.
- Dictionary coverage tests that fail when a mission title, lesson heading, activity title, planet name, or core planet-stat label is missing.

## Still incomplete

This is a substantial dictionary expansion, not a claim of 100% localization. The following content still needs a full translation and review pass:

- Long lesson paragraphs, notes, and scientific explanations.
- Quiz questions, answer options, hints, and explanations throughout all missions.
- Full planet descriptions, fact paragraphs, and image alt descriptions.
- Some dynamically generated messages, cosmetic item descriptions, and secondary pages.

Unknown text intentionally remains in English rather than being replaced with guessed or unreviewed Arabic. Arabic translations should be checked by a fluent Arabic reviewer and a science educator before public release.
