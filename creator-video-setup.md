# Creator introduction video

The About Us page contains a creator video player. To add the video:

1. Rename the exported video file to `creator-intro.mp4`.
2. Copy it into the project's `assets` folder (the same folder that contains `astronaut-jr-logo.png`).
3. The final path must be `assets/creator-intro.mp4`.
4. Rebuild/redeploy the site. The video appears in About Us under **Meet the Creator**.

The video is not autoplayed. Visitors choose when to play it. MP4/H.264 is recommended for broad browser compatibility. Keep a compressed web export so the page loads quickly on mobile connections.
